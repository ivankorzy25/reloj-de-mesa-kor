# Fuentes incluidas

Todas con licencia SIL Open Font License 1.1 (OFL).

| Archivo en `app/src/main/res/font` | Fuente | Origen |
| --- | --- | --- |
| `manrope_bold.ttf` | Manrope Bold | Google Fonts (ver `Manrope-OFL.txt`) |
| `inter_regular.ttf`, `inter_medium.ttf` | Inter | Google Fonts (ver `Inter-OFL.txt`) |
| `plex_cond_light.ttf` | IBM Plex Sans Condensed ExtraLight | paquete `fonts-ibm-plex` de Ubuntu |
| `plex_cond_medium.ttf` | IBM Plex Sans Condensed Medium | paquete `fonts-ibm-plex` de Ubuntu |
| `space_grotesk_light.ttf` | Space Grotesk Light | Ubuntu (`/usr/share/fonts/truetype/space-grotesk`) |
| `dm_mono_light.ttf` | DM Mono Light | Ubuntu (`/usr/share/fonts/truetype/dm-mono`) |

El texto completo de la OFL 1.1 está en `Manrope-OFL.txt` / `Inter-OFL.txt`; es la misma
licencia para IBM Plex, Space Grotesk y DM Mono. "IBM" y "IBM Plex" son marcas de IBM Corp.
